# Contributing to Ajika

Contributions are generally welcome, unless it's AI slop.

If it's AI slop, it's not welcome.

LLM use is allowed, as long as human remains responsible for the output and understands what's
going on. The code is owned by a _human_, not by LLM.

Please make sure that `just test` / `just lint` passes (requires `dylint` installed),
and, ideally, check against CI workflows.

Text in issues, PR descriptions, and comments is expected to receive a human touch at least.

Purely copy-pasted AI output might be ignored.
